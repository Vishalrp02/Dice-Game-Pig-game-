# 🎲 Pig Game

A fun and interactive **2-player dice game** built using **HTML, CSS, and JavaScript**.  
The game is based on luck and strategy — roll the dice, take risks, and race your opponent to **100 points**!

---

## 🚀 Rules of the Game

1. Each player takes turns rolling a dice.
2. The dice value is added to the **current (temporary) score**.
3. If the player rolls a **1**:
   - The current score becomes **0**.
   - The turn immediately switches to the next player.
4. A player can **Hold** at any time:
   - The current score is added to the **total score**.
   - The turn passes to the next player.
5. The first player to reach **100 points** wins the game 🎉.

---

## 🛠️ Built With

- **HTML5** → Page structure
- **CSS3** → Styling & layout
- **JavaScript (ES6)** → Game logic & interactivity
